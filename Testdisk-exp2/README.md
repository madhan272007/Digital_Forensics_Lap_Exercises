# 🧪 Experiment 2 – TestDisk: Partition and File Recovery

## 🎯 Aim

To recover lost or deleted partitions and files using TestDisk, and to verify the recovered data successfully.

## 🛠️ Tools Required

- TestDisk
- Windows System
- Storage device / disk image
- Administrator privileges

## 📖 Theory

TestDisk is an open-source data recovery utility used to recover lost partitions and restore deleted files.

It can be used to:
- Recover deleted or lost partitions
- Repair partition tables
- Recover deleted files
- Identify available partitions
- Verify recovered data

## 📝 Procedure

### Step 1 – Launch TestDisk

1. Download and extract TestDisk.
2. Open the extracted TestDisk folder.
3. Run `testdisk_win.exe` as Administrator.
4. Select **Create** to create a log file.

### Step 2 – Select the Disk

1. TestDisk displays the available disks.
2. Select the required physical disk.
3. Press **Enter** to continue.

### Step 3 – Select Partition Table Type

1. TestDisk detects the partition table type.
2. Select the detected/default option.
3. Press **Enter**.

### Step 4 – Analyse the Disk

1. Select **Analyse**.
2. Press **Enter**.
3. Select **Quick Search**.
4. Wait while TestDisk searches for lost partitions.

### Step 5 – Recover Partition

1. Review the partitions found by TestDisk.
2. Select the required partition.
3. Use the appropriate partition status.
4. Continue with the recovery process.

### Step 6 – Recover Deleted Files

1. Select the required partition.
2. Choose **Advanced**.
3. Select **Undelete**.
4. Browse the deleted files.
5. Select the required files.
6. Copy the files to a safe destination.

### Step 7 – Verify Recovered Data

1. Open the destination folder.
2. Check the recovered files.
3. Verify that the files can be opened successfully.
4. Compare the recovered files with the expected data.

## 🔍 Observation

- TestDisk detected the available disk.
- Lost/deleted partitions were searched.
- Deleted files were identified.
- Required files were recovered to the selected destination.
- Recovered files were verified successfully.

## 📸 Result

The lost/deleted partition and files were successfully recovered using TestDisk, and the recovered data was verified.

## ✅ Conclusion

Thus, partition and file recovery was successfully performed using TestDisk.
